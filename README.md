# CampusFind

### University Lost and Found Management System

**CampusFind – Find. Report. Reclaim.**

CampusFind is a web-based University Lost and Found Management System designed to help university students report missing belongings, report found items, search for reported items, and submit ownership claims to recover their belongings.

The platform provides a centralized system for managing lost and found reports and allows administrators to review ownership claims and manage reported items.

## Objectives

- Provide a centralized lost and found platform for university students.
- Allow students to report lost and found items.
- Enable users to search and filter reported items.
- Allow students to submit ownership claims.
- Enable administrators to verify claims and manage reports.
- Improve the process of recovering lost belongings within the university community.

## User Roles

### 1. Students
Students can:
- Register and log in.
- Report lost and found items.
- Browse and search reported items.
- View item details.
- Submit ownership claims.
- Track their reports and claims.
- Receive notifications about relevant activities.

### 2. Administrators
Administrators can:
- Access the administrative dashboard.
- View and manage item reports.
- Review submitted ownership claims.
- Approve or reject claims.
- Update item statuses.
- Manage inappropriate or invalid reports.

## Main Features

- User registration and authentication.
- Lost and found item reporting.
- Item browsing, searching and filtering.
- Ownership claim submission.
- Administrative claim verification.
- Report and claim tracking.
- Student dashboard.
