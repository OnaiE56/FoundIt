# CampusFind

### University Lost and Found Management System

CampusFind is a web-based platform designed to help
university students report, search for and recover
lost belongings.

## Objectives

- Provide a centralized lost and found platform.
- Allow students to report lost and found items.
- Enable users to search for reported items.
- Allow students to submit ownership claims.
- Enable administrators to verify claims and manage reports.

## Main Features

- User registration and authentication.
- Lost and found item reporting.
- Item search and filtering.
- Ownership claim submission.
- Administrative claim verification.
- Report and claim tracking.
