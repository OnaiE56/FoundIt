# CampusFind
### University Lost and Found Management System

CampusFind is a web-based platform designed to help
university students report, search for and recover
lost belongings.

## Main Features

- User registration and authentication
- Lost and found item reporting
- Item browsing and searching
- Ownership claim submission
- Administrative claim verification
- Report and claim tracking
